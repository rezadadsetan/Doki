# Doki

Portable Windows laptop QC. Created by Reza Dadsetan.

Enter your name and asset number, run battery/disk/driver/update checks, CPU/RAM/SSD/GPU stress and physical checks, then save the HTML/JSON report to Desktop/Doki Reports.

No Jira API, organizational credentials, EDR installer or application updater. Windows Update detection may use Windows services/network. Extract the full release folder and run Doki.exe. Build locally with tools/Build-Exe.ps1.
